## Как пользоваться

1. Выбери тему в таблице выше и открой нужный блокнот или конспект.
2. Блокноты Python можно запускать в Google Colab. Конспекты `.md` удобно читать прямо на GitHub.
3. Примеры `turtle` и проекты Pygame с графическим окном удобнее запускать локально; Roblox-скрипты предназначены для Roblox Studio.

**Важно:** `chess.py` и `pieces.py` находятся в одной папке, поскольку шахматы импортируют модуль фигур. GIF-анимации лежат рядом с конспектом по Turtle, чтобы ссылки на картинки продолжали работать.
