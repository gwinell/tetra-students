# 5. Координаты в Pygame

Важно понимать систему координат Pygame.

Начало координат находится в **левом верхнем углу окна**:

```text
(0, 0) --------------------> X
  |
  |
  |
  |
  v
  Y
```

Поэтому:

- увеличение `x` двигает объект вправо;
- уменьшение `x` двигает объект влево;
- увеличение `y` двигает объект вниз;
- уменьшение `y` двигает объект вверх.

Это особенно важно для реализации прыжка.

# 7. Переменные для прыжка

В программе уже есть три очень важные переменные:

```python
self.velocity_y = 0
self.gravity = 1
self.jump_power = -15
```

Разберём каждую отдельно.

## `velocity_y`

```python
self.velocity_y = 0
```

Это вертикальная скорость динозаврика.

Если:

```python
velocity_y < 0
```

динозаврик движется вверх.

Если:

```python
velocity_y > 0
```

динозаврик движется вниз.

Если:

```python
velocity_y == 0
```

вертикального движения нет.

---

## `gravity`

```python
self.gravity = 1
```

Это сила гравитации.

На каждом кадре мы будем увеличивать вертикальную скорость:

```python
self.velocity_y += self.gravity
```

Например, сразу после прыжка:

```text
velocity_y = -15
```

Через несколько кадров получится примерно так:

```text
-15
-14
-13
-12
...
-2
-1
0
1
2
3
...
```

Сначала скорость отрицательная — динозаврик летит вверх.

Потом скорость приближается к нулю — динозаврик достигает верхней точки прыжка.

Затем скорость становится положительной — начинается падение.

Именно таким образом получается простая имитация физики.

---

## `jump_power`

```python
self.jump_power = -15
```

Это начальная скорость прыжка.

Почему число отрицательное?

Потому что в Pygame уменьшение координаты `y` означает движение вверх.

Когда начинается прыжок, мы присваиваем:

```python
self.velocity_y = self.jump_power
```

то есть:

```python
self.velocity_y = -15
```

После этого динозаврик начинает двигаться вверх.

---

# 8. Переменная `on_ground`

В текущей программе написано:

```python
self.on_groud = True
```

Здесь есть небольшая опечатка: `groud` вместо `ground`.

Лучше написать:

```python
self.on_ground = True
```

Эта переменная нужна, чтобы понимать, стоит ли динозаврик на земле.

Она нужна для запрета бесконечных прыжков в воздухе.

Если этого не сделать, игрок сможет много раз нажимать `SPACE` и буквально летать.

Логика будет такой:

```text
on_ground = True
        ↓
можно прыгать
        ↓
прыжок
        ↓
on_ground = False
        ↓
новый прыжок запрещён
        ↓
динозаврик касается земли
        ↓
on_ground = True
```

# Часть 2. Как заставить динозаврика прыгать

Для прыжка нужно выполнить четыре действия:

1. Обработать нажатие клавиши.
2. Установить отрицательную вертикальную скорость.
3. Каждый кадр применять гравитацию.
4. Остановить падение при соприкосновении с землёй.

---

# 23. Метод `jump()`

Сейчас метод пустой:

```python
def jump(self):
```

Его можно реализовать так:

```python
def jump(self):
    if self.on_ground:
        self.velocity_y = self.jump_power
        self.on_ground = False
```

Разберём по шагам.

## Проверка земли

```python
if self.on_ground:
```

Прыгать разрешено только тогда, когда динозаврик стоит на земле.

## Начало прыжка

```python
self.velocity_y = self.jump_power
```

Так как:

```python
self.jump_power = -15
```

получается:

```python
self.velocity_y = -15
```

Динозаврик начинает движение вверх.

## Запрет второго прыжка

```python
self.on_ground = False
```

Теперь повторный вызов `jump()` ничего не сделает до тех пор, пока динозаврик снова не окажется на земле.

---

# 24. Почему одного `jump()` недостаточно

Если просто изменить `velocity_y`, положение `y` ещё не изменится само по себе.

Нам нужен метод, который каждый кадр будет обновлять физику.

Например:

```python
def update(self):
    self.velocity_y += self.gravity
    self.y += self.velocity_y
```

Первая строка:

```python
self.velocity_y += self.gravity
```

изменяет скорость под действием гравитации.

Вторая:

```python
self.y += self.velocity_y
```

изменяет положение динозаврика.

---

# 25. Что происходит во время прыжка

Предположим:

```python
jump_power = -15
gravity = 1
```

Сразу после прыжка:

```text
velocity_y = -15
```

Следующие кадры:

```text
кадр 1: velocity_y = -14
кадр 2: velocity_y = -13
кадр 3: velocity_y = -12
...
кадр 14: velocity_y = -1
кадр 15: velocity_y = 0
кадр 16: velocity_y = 1
кадр 17: velocity_y = 2
...
```

Пока скорость отрицательная, координата `y` уменьшается.

Динозаврик поднимается.

Когда скорость равна нулю, достигнута верхняя точка.

Когда скорость становится положительной, координата `y` растёт.

Динозаврик падает.

---

# 26. Как определить уровень земли

Пусть верхняя координата земли равна:

```python
ground_y = 350
```

Высота динозаврика равна 50.

Чтобы нижняя сторона динозаврика находилась на `y = 350`, его верхняя координата должна быть:

```text
350 - 50 = 300
```

Именно поэтому начальная позиция:

```python
Dinosaur(100, 300)
```

подходит для динозаврика высотой 50 пикселей.

Можно сохранить уровень поверхности в виде:

```python
ground_y = 300
```

если под `ground_y` мы понимаем именно **координату верхней стороны динозаврика, когда он стоит на земле**.

Тогда проверка будет такой:

```python
if self.y >= ground_y:
    self.y = ground_y
    self.velocity_y = 0
    self.on_ground = True
```

---

# 27. Полный метод `update()`

```python
def update(self):
    self.velocity_y += self.gravity
    self.y += self.velocity_y

    ground_y = 300

    if self.y >= ground_y:
        self.y = ground_y
        self.velocity_y = 0
        self.on_ground = True
```

Здесь важно присвоить:

```python
self.y = ground_y
```

Иначе объект может немного проваливаться ниже земли.

После приземления скорость сбрасывается:

```python
self.velocity_y = 0
```

и прыжок снова разрешается:

```python
self.on_ground = True
```

# 28. Обработка клавиши SPACE

Теперь нужно вызвать `jump()` при нажатии пробела.

В обработчик событий добавляем:

```python
if event.type == pygame.KEYDOWN:
    if event.key == pygame.K_SPACE:
        dino.jump()
```

Полный фрагмент:

```python
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False

    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            dino.jump()
```

`pygame.KEYDOWN` означает событие нажатия клавиши.

`pygame.K_SPACE` обозначает пробел.

---

# 29. Вызов `update()` в игровом цикле

Метод необходимо вызывать на каждом кадре:

```python
dino.update()
```

Например:

```python
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                dino.jump()

    dino.update()

    screen.fill((255, 255, 255))
    dino.draw(screen)

    pygame.display.update()
    clock.tick(60)
```

Теперь последовательность выглядит так:

```text
SPACE
  ↓
jump()
  ↓
velocity_y = -15
  ↓
каждый кадр вызывается update()
  ↓
gravity увеличивает velocity_y
  ↓
y изменяется
  ↓
динозаврик поднимается
  ↓
скорость становится положительной
  ↓
динозаврик падает
  ↓
касание земли
  ↓
velocity_y = 0
on_ground = True
```

# Часть 3. Как добавить препятствие

В оригинальной игре Chrome динозаврик стоит примерно на месте, а препятствия движутся справа налево.

Это удобно и для нашей игры.

Вместо движения динозаврика по экрану мы будем двигать кактус навстречу ему.

---

# 30. Создание класса `Obstacle`

Можно создать отдельный класс:

```python
class Obstacle:

        self.x = x
        self.y = y
        self.width = 30
        self.height = 50
        self.speed = 6
```

Здесь:

```python

self.y
```

— положение препятствия.

```python
self.width
self.height
```

— его размеры.

```python
self.speed = 6
```

— скорость движения влево.

# 32. Движение препятствия

Препятствие должно двигаться справа налево.

Поэтому каждый кадр уменьшаем `x`:

```python
def update(self):
    self.x -= self.speed
```

Например:

```text

x = 794
x = 788
x = 782
...
```

Препятствие постепенно приближается к динозаврику.

# 35. Возвращение препятствия вправо

Когда препятствие полностью ушло за левую границу экрана, можно вернуть его вправо.

Проверка:

```python
if obstacle.x + obstacle.width < 0:
    obstacle.x = WIDTH
```

Почему используется:

```python
obstacle.x + obstacle.width
```

Потому что `obstacle.x` обозначает левый край препятствия.

Нужно дождаться, пока за границу уйдёт весь прямоугольник.

# Часть 4. Как проверить столкновение

Следующий важный этап — определить, коснулся ли динозаврик препятствия.

---

# 36. Использование `pygame.Rect`

Pygame умеет проверять столкновения прямоугольников.

Для динозаврика можно создать прямоугольную область:

```python
dino_rect = pygame.Rect(
    dino.x,
    dino.y,
    dino.width,
    dino.height
)
```

Для препятствия:

```python
obstacle_rect = pygame.Rect(
    obstacle.x,
    obstacle.y,
    obstacle.width,
    obstacle.height
)
```

Затем выполнить:

```python
if dino_rect.colliderect(obstacle_rect):
    running = False
```

Метод `colliderect()` возвращает `True`, если два прямоугольника пересекаются.

---

# 37. Более удобный вариант — метод `get_rect()`

Чтобы не писать создание прямоугольника каждый раз, можно добавить каждому классу метод.

Для динозаврика:

```python
def get_rect(self):
    return pygame.Rect(
        self.x,
        self.y,
        self.width,
        self.height
    )
```

Для препятствия:

```python
def get_rect(self):
    return pygame.Rect(
        self.x,
        self.y,
        self.width,
        self.height
    )
```

Тогда проверка становится очень короткой:

```python
if dino.get_rect().colliderect(obstacle.get_rect()):
    running = False
```

# 39. Пример класса `Dinosaur` после реализации прыжка

```python
class Dinosaur:
    def __init__(self, x, y):
        self.x = x
        self.y = y

        self.width = 50
        self.height = 50

        self.velocity_y = 0
        self.gravity = 1
        self.jump_power = -15

        self.on_ground = True

    def draw(self, screen):
        pygame.draw.rect(
            screen,
            (0, 150, 0),
            (self.x, self.y, self.width, self.height)
        )

    def jump(self):
        if self.on_ground:
            self.velocity_y = self.jump_power
            self.on_ground = False

    def update(self):
        self.velocity_y += self.gravity
        self.y += self.velocity_y

        ground_y = 300

        if self.y >= ground_y:
            self.y = ground_y
            self.velocity_y = 0
            self.on_ground = True

    def get_rect(self):
        return pygame.Rect(
            self.x,
            self.y,
            self.width,
            self.height
        )
```

# 43. Главное, что нужно понять

В простых играх объект обычно состоит из двух основных частей:

```text
данные объекта
+
методы, которые изменяют эти данные
```

У динозаврика данными являются:

```python
x
y
width
height
velocity_y
gravity
jump_power
on_ground
```

А методами:

```python
draw()
jump()
update()
get_rect()
```

Для прыжка самое важное — разделять **скорость** и **координату**.

Мы не просто пишем:

```python
self.y -= 100
```

потому что тогда динозаврик мгновенно телепортируется вверх.

Вместо этого создаётся вертикальная скорость:

```python
self.velocity_y = -15
```

а затем на каждом кадре гравитация постепенно изменяет эту скорость:

```python
self.velocity_y += self.gravity
self.y += self.velocity_y
```

Благодаря этому движение выглядит как настоящий прыжок: подъём замедляется, в верхней точке скорость становится нулевой, а затем начинается ускоряющееся падение.

Препятствие работает по ещё более простой схеме: каждый кадр его координата `x` уменьшается:

```python
self.x -= self.speed
```

Поэтому оно движется справа налево.

Когда прямоугольник динозаврика пересекается с прямоугольником препятствия, происходит столкновение:

```python
if dino.get_rect().colliderect(obstacle.get_rect()):
```

На этом принципе уже можно построить полноценную простую версию игры в стиле Chrome Dinosaur.
