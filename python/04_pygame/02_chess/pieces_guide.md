## Зачем отдельный файл?

```
┌─────────────────┐         ┌─────────────────┐
│    main.py      │         │   pieces.py     │
│                 │         │                 │
│  • Логика игры  │         │  • Как выглядит │
│  • Доска 8×8    │◄───────►│    каждая фигура│
│  • Ходы игрока  │  импорт │  • Отрисовка    │
│  • События      │         │    примитивами  │
└─────────────────┘         └─────────────────┘
```

**Разделение ответственности** — золотое правило программирования:

| Файл | Отвечает за | Не знает про |
|------|-------------|--------------|
| `main.py` | Где стоит фигура, чей ход, правила | Как нарисовать коня |
| `pieces.py` | Как нарисовать фигуру любым цветом | Где она стоит на доске |

> 💡 Если захотите поменять внешний вид фигур — правите только `pieces.py`. Логика игры останется нетронутой.

## Общая архитектура: 5 шагов отрисовки

Каждая функция (`draw_king`, `draw_queen`...) работает **по одной схеме**:

```
ШАГ 1: Создать temp Surface 400×400 с прозрачностью
           │
           ▼
ШАГ 2: Определить центр: cx=200, cy=200
           │
           ▼
ШАГ 3: Рисуем фигуру кусочками на temp
        (основание → тело → голова → детали)
           │
           ▼
ШАГ 4: Масштабировать temp → CELL×CELL
           │
           ▼
ШАГ 5: Скопировать (blit) на основной экран в (cell_x, cell_y)
```

## Ключевые концепции

### 1. Прозрачный холст (SRCALPHA)

```python
temp = pygame.Surface((400, 400), pygame.SRCALPHA)
```

**Что это:** временный "лист бумаги" размером 400×400 пикселей.

**Зачем SRCALPHA:**

| Без SRCALPHA | С SRCALPHA |
|--------------|------------|
| Фон temp = чёрный | Фон temp = прозрачный |
| При blit закроет клетку доски | Видна клетка под фигурой |
| ❌ Фигура в чёрной рамке | ✅ Фигура "парит" на клетке |

> 🎨 Представьте, что рисуете на прозрачной плёнке, а не на белой бумаге.

**Почему именно 400×400?**

Это "виртуальный" холст высокого разрешения. На нём:
- Координаты круглые (200, 100, 50...) — удобно считать
- Детали чёткие и пропорциональные
- Потом масштабируем до любого CELL

```
┌─────────────────────────────┐
│         400 × 400           │
│                             │
│           ●                 │  ← центр (200, 200)
│                             │
│    ┌─────────┐              │  ← фигура нарисована
│    │  тело   │              │     относительно центра
│    └─────────┘              │
│                             │
└─────────────────────────────┘
           │
           ▼ scale
┌─────────┐
│ CELL×CELL│  ← готова к копированию на доску
└─────────┘
```

### 2. Паттерн "обводка + заливка"

Каждая деталь фигуры рисуется **дважды**:

```python
# 1. ОБВОДКА: чуть больше, тёмный цвет
pygame.draw.rect(temp, OUTLINE, (x - 2, y - 2, w + 4, h + 4))

# 2. ЗАЛИВКА: "правильный" размер, цвет фигуры
pygame.draw.rect(temp, color, (x, y, w, h))
```

**Как это работает:**

```
Обводка:  x-2, y-2, w+4, h+4     Заливка:  x, y, w, h
         ┌─────────────────┐              ┌─────────┐
         │ ░░░░░░░░░░░░░░░ │              │ ███████ │
         │ ░┌───────────┐░ │              │ ███████ │
         │ ░│  ЗАЛИВКА  │░ │      →       │ ███████ │
         │ ░└───────────┘░ │              │ ███████ │
         │ ░░░░░░░░░░░░░░░ │              └─────────┘
         └─────────────────┘

         ░ = OUTLINE (тёмный)     █ = color (белый/чёрный)
```

**Зачем смещение на 2 пикселя?**

- `x - 2`, `y - 2` — сдвигаем влево и вверх
- `w + 4`, `h + 4` — увеличиваем на 2 с каждой стороны
- Итого: обводка торчит на 2 пикселя за края заливки со всех сторон

> 🖊️ Это как раскраска в детской раскраске: сначала толстый чёрный контур, потом заливаем внутри.

---

### 3. Координаты относительно центра

```python
cx, cy = 200, 200  # центр temp-холста
```

Все детали позиционируются **относительно центра**, а не от угла:

```python
x = cx - w // 2   # левый край = центр - половина ширины
```

**Пример:** деталь шириной 100 в центре холста:

```
        0         100       200       300       400
        │         │         │         │         │
        ├─────────┴─────────┴─────────┤
        │    ←─── 50 ───→│←─── 50 ───→│
        │                 │███████████│
        │                 │███████████│  w = 100
        │                 │███████████│
        │                 ▲            
        │               cx=200
        │
        x = 200 - 100//2 = 150
```

**По вертикали** используется другая логика — детали "наращиваются" снизу вверх:

```python
y = cy - h + 40
# cy = 200 (центр)
# h = 30 (высота детали)
# 40 = отступ вниз от центра
# y = 200 - 30 + 40 = 210 → чуть ниже центра
```

### 4. Масштабирование

```python
scaled = pygame.transform.scale(temp, (CELL, CELL))
surf.blit(scaled, (cell_x, cell_y))
```

| Параметр | Значение | Пояснение |
|----------|----------|-----------|
| `temp` | 400×400 | Исходное изображение фигуры |
| `(CELL, CELL)` | 80×80 | Целевой размер (одна клетка) |
| `surf` | 640×640 | Основной экран (доска) |
| `(cell_x, cell_y)` | 0..560 | Координаты клетки на доске |

**Почему не рисовать сразу на доске?**

1. **Пропорции:** на 400×400 легко считать координаты
2. **Масштабируемость:** поменяли CELL — всё адаптировалось
3. **Центрирование:** фигура всегда в центре клетки, независимо от размера

## Разбор фигур

### Король

```
        ╔═══╗
        ║ ╳ ║   ← крест
        ╠═══╣   ← голова
        ║   ║
        ║   ║   ← тело (высокое)
        ║   ║
        ╠═══╣   ← среднее основание
        ╚═══╝   ← большое основание
```

**Детали (снизу вверх):**

| # | Деталь | Размер | Особенность |
|---|--------|--------|-------------|
| 1 | Большое основание | 100×30 | Самая широкая часть |
| 2 | Среднее основание | 80×20 | Уже, чем №1 |
| 3 | Тело | 50×110 | Высокий узкий прямоугольник |
| 4 | Голова | 90×25 | Горизонтальная планка |
| 5 | Крест верт. | 14×50 | Штанга креста |
| 6 | Крест гориз. | 44×14 | Перекладина креста |

> 👑 Крест — отличительный знак короля. Рисуется двумя пересекающимися прямоугольниками.

---

### Ферзь

```
        ▲  ▲  ▲
        ║  ║  ║   ← три пики
        ╠═══════╣   ← голова
        ║       ║
        ║       ║   ← тело (её выше, чем у короля)
        ║       ║
        ╠═══════╣
        ╚═══════╝
```

**Отличия от короля:**

| | Король | Ферзь |
|---|--------|-------|
| Верх | Крест | Три пики (шипа) |
| Тело | 110 px | 120 px (выше) |
| Голова | 90×25 | 110×30 (шире) |
| Переход к голове | Нет | Есть широкая планка 80×20 |

**Как рисуются пики:**

```python
baseb_w5 = baseb_w4 // 5   # ширина головы / 5 = 22
# Три пики с интервалом в 2 ширины:
# Пика 1: x = левый край головы
# Пика 2: x = левый край + 22*2
# Пика 3: x = левый край + 22*4
```

```
Ширина головы = 110
    ├─22─┤←──22──→├─22─┤←──22──→├─22─┤
    [пика1]       [пика2]       [пика3]
    ▲                           ▲
    └─ расстояние между крайними = 88 ─┘
```

---

### Ладья

```
        ▓ ▓ ▓ ▓ ▓   ← 5 зубцов
        ╔═════════╗   ← голова
        ║         ║
        ║    ▲    ║   ← центральная пика
        ║         ║   ← ствол
        ╚═════════╝   ← основание
```

**Уникальные детали:**

1. **Зубцы** — 5 маленьких прямоугольников наверху, нарисованных в цикле:
   ```python
   for i in range(5):
       tx = head_x + i * tooth_w   # 0, 12, 24, 36, 48
   ```

2. **Центральная пика** — выше всех зубцов, по центру:
   ```python
   # Обводка: ширина 24, высота 29
   pygame.draw.rect(temp, OUTLINE, (cx - 12, body_y - 47, 24, 29))
   # Заливка: ширина 20, высота 25 (на 2 пикселя меньше)
   pygame.draw.rect(temp, color, (cx - 10, body_y - 45, 20, 25))
   ```

> 🏰 Ладья — единственная фигура с зубцами. Это символизирует зубцы башни.

---

### Слон

```
          ●           ← шарик
         ╱╲          ← верхушка шапки
        ╱──╲         ← шапка
       ╱    ╲        ← тело
      │  ┌┐  │       ← срез (ступенька справа)
      ╠══════╣       ← основания
      ╚══════╝
```

**Отличительные черты:**

| Деталь | Описание |
|--------|----------|
| Шарик наверху | 18×18 квадрат (имитирует шар) |
| Многоярусная шапка | Три уровня: 40×20, 70×25, 45×100 |
| Срез справа | 10×28 прямоугольник — "ступенька" на теле |

**Зачем срез?**

Без среза слон выглядел бы как король без креста. Срез придаёт фигуре индивидуальность и делает её узнаваемой.

```python
# Срез — сдвинут вправо от центра
x = cx + 18   # центр + 18 пикселей
y = cy - 90   # на уровне верхней части тела
```

### Конь

**Самая сложная фигура** — 15+ отдельных деталей:

```
           ▓▓          ← ухо
          ┌──┐         ← голова
          │  │▓        ← глаз
          └──┘──┐      ← морда
            │   │
           ┌┴───┘      ← шея (2 части)
           │           
      ▓▓▓  ┌────┐     ← грива (3 пряди)
      │  │ │    │     ← тело
      └──┘ └────┘
      ││││ ││││      ← 4 ноги с копытами
      ▓▓▓▓ ▓▓▓▓      ← основание

      ┌──┐           ← хвост
      │  │
      └──┘
```

**Детали коня:**

| # | Деталь | Количество | Примечание |
|---|--------|------------|------------|
| 1 | Основание | 1 | 90×25 |
| 2 | Ноги | 4 | С копытами цвета (20,20,20) |
| 3 | Тело | 1 | 55×35, широкое |
| 4 | Шея | 2 части | Идёт вверх-вправо |
| 5 | Голова | 1 | 38×24, сдвинута вправо |
| 6 | Морда | 1 | 20×14, ещё правее |
| 7 | Ухо | 1 | 8×18, торчит вверх |
| 8 | Грива | 3 пряди | В цикле enumerate |
| 9 | Хвост | 2 части | Гориз.+верт. |
| 10 | Глаз | 1 | Только обводка, 5×5 |

**Грива в цикле:**

```python
for i, gx in enumerate([cx + 18, cx + 22, cx + 26]):
    gy = cy - 48 + i * 5
```

| i | gx | gy | Смещение |
|---|-----|-----|----------|
| 0 | cx+18 | cy-48 | левая, самая высокая |
| 1 | cx+22 | cy-43 | средняя, на 5 ниже |
| 2 | cx+26 | cy-38 | правая, ещё на 5 ниже |

> 🐴 Конь смотрит **вправо** — все части головы сдвинуты вправо от центра.

**Копыта:**

```python
pygame.draw.rect(temp, (20, 20, 20), (lx, cy + 40, leg_w, 10))
```

Цвет `(20, 20, 20)` — отдельный тёмный оттенок, отличный от OUTLINE `(30, 30, 30)`. Это создаёт микро-контраст.

---

### Пешка

**Самая простая фигура** — всего 4 детали:

```
         ╭──╮
        ╱    ╲      ← голова (овал)
        │    │
        ╰────╯
          ││
          ││      ← тело
          ││
         ════     ← среднее основание
        ════════   ← большое основание
```

**Единственная фигура с `ellipse`:**

```python
# Овал рисуется внутри прямоугольника
pygame.draw.ellipse(temp, OUTLINE, (cx - 27, cy - 77, 54, 54))  # обводка
pygame.draw.ellipse(temp, color,   (cx - 25, cy - 75, 50, 50))  # заливка
```

| Параметр | Обводка | Заливка | Разница |
|----------|---------|---------|---------|
| x | cx-27 | cx-25 | +2 |
| y | cy-77 | cy-75 | +2 |
| ширина | 54 | 50 | -4 |
| высота | 54 | 50 | -4 |

Когда ширина = высота, `ellipse` рисует **круг**.

## Частые вопросы

### Почему не использовать картинки (PNG)?

| Картинки | Программная отрисовка |
|----------|----------------------|
| Нужны файлы рядом с кодом | Всё в одном .py файле |
| Масштабирование = размытие | Чёткие края при любом CELL |
| Цвет фиксирован | Можно менять color параметром |
| Тяжелее для git | Легко версионировать |

### Что будет, если изменить CELL?

```python
CELL = 120  # вместо 80
```

✅ Всё адаптируется автоматически! Фигуры масштабируются пропорционально.

### Почему обводка рисуется первой?

Потому что pygame рисует "поверх". Если нарисовать заливку первой, а потом обводку — обводка закроет края заливки. А нам нужно, чтобы обводка была **вокруг**.

### Зачем `//` (целочисленное деление)?

```python
w // 2   # вместо w / 2
```

Pygame требует **целые числа** для координат. `//` гарантирует, что результат будет `int`, а не `float`.

### Почему у коня глаз без заливки?

```python
pygame.draw.rect(temp, OUTLINE, (cx + 44, cy - 78, 5, 5))
# Нет второго вызова с color!
```

Глаз — это просто маленький квадрат-обводка. Внутри него виден фон фигуры (цвет тела), что создаёт эффект "пустого глаза".

## 📐 Схема координат temp-холста (400×400)

```
     0      100     200     300     400
     │       │       │       │       │
   ──┼───────┼───────┼───────┼───────┼──  0
     │       │       │       │       │
     │       │   ┌───┴───┐   │       │
     │       │   │       │   │       │     ← тело фигуры
   ──┼───────┼───┤  200  ├───┼───────┼── 200  ← cy (центр)
     │       │   │   ●   │   │       │
     │       │   └───┬───┘   │       │
     │       │       │       │       │
   ──┼───────┼───────┼───────┼───────┼── 400
     │       │       │       │       │
     └───────┴───────┴───────┴───────┘
                         ↑
                       cx=200
```

## 🎯 Итог

| Концепция | Где в коде | Зачем нужна |
|-----------|-----------|-------------|
| `SRCALPHA` | `pygame.Surface((400,400), ...)` | Прозрачный фон фигуры |
| Обводка + заливка | Каждая деталь рисуется 2 раза | Толстый контур вокруг частей |
| Центрирование | `cx - w//2` | Фигура всегда по центру клетки |
| Масштабирование | `pygame.transform.scale` | Один код для любого CELL |
| `blit` | `surf.blit(scaled, ...)` | Перенос готовой фигуры на доску |

**Поздравляю!** Теперь вы понимаете, как из простых прямоугольников и одного овала собираются узнаваемые шахматные фигуры. Это — основа векторной графики: сложные формы из простых примитивов. ♟️
