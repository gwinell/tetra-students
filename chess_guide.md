## Что делает эта программа?

Это **графический интерфейс шахматной доски** на Python с использованием библиотеки Pygame. Вот что умеет программа:

- ✅ Отображает шахматную доску 8×8 с классической раскраской
- ✅ Рисует все 32 фигуры в начальной позиции
- ✅ Позволяет **кликом мыши выбрать фигуру** (подсвечивает клетку жёлтым)
- ✅ Позволяет **переместить фигуру** на любую другую клетку вторым кликом
- ⚠️ **Пока НЕ проверяет правила шахмат** — можно ходить куда угодно

Это **скелет шахматной программы**. Логика правил (как ходит конь, нельзя есть своих и т.д.) ещё не реализована, но структура позволяет легко её добавить.

## Что такое Pygame?

**Pygame** — это библиотека Python для создания 2D-игр. Она берёт на себя "рутину":

| Задача | Что делает Pygame |
|--------|-------------------|
| Создать окно | `pygame.display.set_mode()` |
| Рисовать прямоугольники, круги, линии | `pygame.draw.rect()`, `pygame.draw.circle()` |
| Отслеживать клики мыши | `pygame.event.get()` с типом `MOUSEBUTTONDOWN` |
| Ограничить FPS | `clock.tick(60)` |
| Обновить экран | `pygame.display.flip()` |

> 💡 **Аналогия:** Pygame — это как набор кистей и холста для художника. Он не рисует картину за вас, но даёт все инструменты.

```python
import pygame
from pieces import (
```

**Что происходит:**

- `pygame.init()` — **обязательный вызов** перед использованием pygame. Он подготавливает внутренние системы: видео, звук, обработку событий

### 2. Цвета

```python
LIGHT_SQUARE = (240, 217, 181)
DARK_SQUARE  = (181, 136, 99)
WHITE_PIECE  = (230, 230, 230)
BLACK_PIECE  = (60, 60, 60)
```

**Модель RGB:**

В компьютерной графике цвет задаётся тремя числами — **Red, Green, Blue** (Красный, Зелёный, Синий). Каждое число от `0` до `255`.

| Значение | Цвет |
|----------|------|
| `(255, 0, 0)` | Красный |
| `(0, 255, 0)` | Зелёный |
| `(0, 0, 255)` | Синий |
| `(255, 255, 255)` | Белый |
| `(0, 0, 0)` | Чёрный |
| `(240, 217, 181)` | Светло-бежевый (наша "белая" клетка) |

> 🎨 Фигуры не чисто белые/чёрные, чтобы контрастировать с клетками доски.

### 3. Представление доски

```python
board = [
    ['r', 'n', 'b', 'q', 'k', 'b', 'n', 'r'],
    ['p'] * 8,
    [None] * 8,
    [None] * 8,
    [None] * 8,
    [None] * 8,
    ['P'] * 8,
    ['R', 'N', 'B', 'Q', 'K', 'B', 'N', 'R'],
]
```

**Как это устроено:**

`board` — это **список списков** (двумерный массив) 8×8.

```
        col=0  col=1  col=2  col=3  col=4  col=5  col=6  col=7
row=0 [  'r',   'n',   'b',   'q',   'k',   'b',   'n',   'r'  ]  ← чёрные тяжёлые
row=1 [  'p',   'p',   'p',   'p',   'p',   'p',   'p',   'p'  ]  ← чёрные пешки
row=2 [ None,  None,  None,  None,  None,  None,  None,  None ]  ← пусто
row=3 [ None,  None,  None,  None,  None,  None,  None,  None ]  ← пусто
row=4 [ None,  None,  None,  None,  None,  None,  None,  None ]  ← пусто
row=5 [ None,  None,  None,  None,  None,  None,  None,  None ]  ← пусто
row=6 [  'P',   'P',   'P',   'P',   'P',   'P',   'P',   'P'  ]  ← белые пешки
row=7 [  'R',   'N',   'B',   'Q',   'K',   'B',   'N',   'R'  ]  ← белые тяжёлые
```

**Обозначения фигур:**

| Буква | Фигура | Пример в коде |
|-------|--------|---------------|
| `k` / `K` | Король (King) | `'k'` = чёрный, `'K'` = белый |
| `q` / `Q` | Ферзь (Queen) | `'q'` = чёрный, `'Q'` = белый |
| `r` / `R` | Ладья (Rook) | `'r'` = чёрный, `'R'` = белый |
| `b` / `B` | Слон (Bishop) | `'b'` = чёрный, `'B'` = белый |
| `n` / `N` | Конь (kNight) | `'n'` = чёрный, `'N'` = белый |
| `p` / `P` | Пешка (Pawn) | `'p'` = чёрный, `'P'` = белый |
| `None` | Пустая клетка | — |

**Правило заглавных букв:**
- **Заглавная** буква (`'K'`, `'Q'`...) = **белая** фигура
- **Строчная** буква (`'k'`, `'q'`...) = **чёрная** фигура

**Почему `['p'] * 8`?**

Это Python-идиома. `['p'] * 8` создаёт список `['p', 'p', 'p', 'p', 'p', 'p', 'p', 'p']` — 8 пешек в ряд. То же самое с `[None] * 8` — 8 пустых клеток.

### 4. Словарь отрисовки DRAW_MAP

```python
DRAW_MAP = {
    'k': draw_king,    'q': draw_queen,   'r': draw_rook,
    'b': draw_bishop,  'n': draw_knight,  'p': draw_pawn,
}
```

**Что это такое:**

Это **словарь** (dictionary), который сопоставляет букву фигуры с **функцией** её отрисовки.

```
┌─────────┬─────────────────┐
│  Ключ   │     Значение    │
├─────────┼─────────────────┤
│   'k'   │  функция draw_king  │
│   'q'   │  функция draw_queen │
│   'r'   │  функция draw_rook  │
│  ...    │      ...        │
└─────────┴─────────────────┘
```

**Как используется:**

```python
p = 'Q'                    # выбрали белого ферзя
func = DRAW_MAP[p.lower()] # p.lower() → 'q' → берём draw_queen
func(screen, x, y, color)  # вызываем функцию отрисовки
```

> 💡 **Важно:** в словаре ключи — строчные буквы, поэтому перед поиском делаем `.lower()`, чтобы и `'Q'`, и `'q'` нашли `draw_queen`.

### 7. Функция `draw_board()`

```python
def draw_board():
    for r in range(8):
        for c in range(8):
            color = LIGHT_SQUARE if (r + c) % 2 == 0 else DARK_SQUARE
            rect = pygame.Rect(c * CELL, r * CELL, CELL, CELL)
            pygame.draw.rect(screen, color, rect)

            if selected == (r, c):
                pygame.draw.rect(screen, (255, 255, 0), rect, 3)
```

**Разбор по шагам:**

#### Шаг 1: Двойной цикл
```python
for r in range(8):
    for c in range(8):
```
Перебираем все 64 клетки. `r` — строка (0..7), `c` — столбец (0..7).

#### Шаг 2: Определяем цвет клетки
```python
color = LIGHT_SQUARE if (r + c) % 2 == 0 else DARK_SQUARE
```

| r | c | r+c | (r+c)%2 | Цвет |
|---|---|-----|---------|------|
| 0 | 0 | 0 | 0 | Светлый |
| 0 | 1 | 1 | 1 | Тёмный |
| 0 | 2 | 2 | 0 | Светлый |
| 1 | 0 | 1 | 1 | Тёмный |

Это создаёт шахматный узор: соседние клетки всегда разного цвета.

#### Шаг 3: Создаём прямоугольник
```python
rect = pygame.Rect(c * CELL, r * CELL, CELL, CELL)
```

`pygame.Rect(x, y, ширина, высота)` — объект, описывающий прямоугольную область.

```
x = c * CELL   ← отступ слева (0, 80, 160, 240...)
y = r * CELL   ← отступ сверху (0, 80, 160, 240...)
ширина = CELL  ← 80 пикселей
высота = CELL  ← 80 пикселей
```

#### Шаг 4: Рисуем клетку
```python
pygame.draw.rect(screen, color, rect)
```

Рисует **заполненный** прямоугольник на `screen` цветом `color`.

#### Шаг 5: Подсветка выбранной клетки
```python
if selected == (r, c):
    pygame.draw.rect(screen, (255, 255, 0), rect, 3)
```

Если текущая клетка — выбранная, рисуем вокруг неё **жёлтую рамку** толщиной 3 пикселя.

> 🟨 Последний аргумент `3` = толщина линии. Если его не указать, прямоугольник будет залит (а мы хотим только рамку).

### 8. Функция `draw_pieces()`

```python
def draw_pieces():
    for r in range(8):
        for c in range(8):
            p = board[r][c]
            if p is None:
                continue
            func = DRAW_MAP[p.lower()]
            color = WHITE_PIECE if p.isupper() else BLACK_PIECE
            func(screen, c * CELL, r * CELL, color)
```

**Разбор:**

1. Проходим по всей доске
2. `p = board[r][c]` — берём содержимое клетки
3. `if p is None: continue` — пустая клетка, пропускаем
4. `func = DRAW_MAP[p.lower()]` — находим функцию отрисовки (например, `draw_knight`)
5. `color = WHITE_PIECE if p.isupper() else BLACK_PIECE` — определяем цвет
   - `'N'.isupper()` → `True` → белый
   - `'n'.isupper()` → `False` → чёрный
6. `func(screen, c * CELL, r * CELL, color)` — рисуем фигуру!

> 🎨 Фигуры рисуются **поверх** доски, поэтому `draw_pieces()` вызывается **после** `draw_board()`.

### 9. Главный игровой цикл

```python
running = True
while running:
    for event in pygame.event.get():
        ...

    screen.fill((0, 0, 0))
    draw_board()
    draw_pieces()
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

Это **сердце любой игры на pygame**. Цикл работает примерно так:

```
┌─────────────────────────────────────────┐
│           НАЧАЛО ЦИКЛА                  │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  1. Обработать все события (мышь,       │
│     клавиатура, закрытие окна)          │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  2. Очистить экран (залить чёрным)      │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  3. Нарисовать доску                    │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  4. Нарисовать фигуры                   │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  5. Показать результат на экране        │
│     (display.flip)                      │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  6. Подождать до следующего кадра       │
│     (clock.tick(60) → 60 FPS)           │
└─────────────────┬───────────────────────┘
                  ▼
              (повтор)
```

**Зачем `screen.fill((0, 0, 0))`?**

Без очистки экрана каждый новый кадр накладывался бы на старый. Фигуры "размножались" бы и оставляли следы. Чёрная заливка — это "ластик".

**Зачем `pygame.display.flip()`?**

Pygame рисует в **скрытом буфере** (в памяти). `flip()` копирует это на экран. Без него пользователь ничего не увидит!

## Как работает выбор и перемещение фигур

Вот ключевой кусок кода обработки мыши:

```python
elif event.type == pygame.MOUSEBUTTONDOWN:
    col = event.pos[0] // CELL
    row = event.pos[1] // CELL

    if selected is None:
        # ФАЗА 1: Выбор фигуры
        if board[row][col] is not None:
            selected = (row, col)
    else:
        # ФАЗА 2: Перемещение
        if (row, col) != selected:
            board[row][col] = board[selected[0]][selected[1]]
            board[selected[0]][selected[1]] = None
        selected = None
```

### Перевод координат мыши в клетки

Мышь даёт координаты в **пикселях** (например, `x=250, y=180`). Нам нужны **номера клеток**.

```
x = 250 пикселей
CELL = 80 пикселей

col = 250 // 80 = 3   (целочисленное деление)
      ↓
    клетка 3 (4-я слева, счёт с 0)
```

Оператор `//` — это **целочисленное деление** (без остатка).

### Две фазы хода

```
Клик 1: selected = None
        ↓
    Клетка с фигурой?
        ↓ ДА
    selected = (row, col)
        ↓
    [клетка подсвечивается жёлтым]
        ↓
Клик 2: selected = (row, col)
        ↓
    Кликнули на другую клетку?
        ↓ ДА
    Перемещаем фигуру
    selected = None
        ↓
    [ход завершён]
```

**Как происходит перемещение:**

```python
# До хода:
# board[6][3] = 'P'   (белая пешка)
# board[4][3] = None  (пусто)

board[row][col] = board[selected[0]][selected[1]]
# board[4][3] = board[6][3] → board[4][3] = 'P'

board[selected[0]][selected[1]] = None
# board[6][3] = None

# После хода:
# board[6][3] = None  (пусто)
# board[4][3] = 'P'   (пешка здесь!)
```

> ⚠️ **Важно:** программа пока НЕ проверяет:
> - Можно ли так ходить по правилам шахмат
> - Не бьём ли свою фигуру
> - Не выходит ли ход за пределы доски
> - Чей сейчас ход (белые/чёрные)

## Карта потока данных

```
┌──────────────┐     клик мыши      ┌──────────────┐
│   Игрок      │ ─────────────────→ │   Программа  │
│              │   (x=250, y=180)   │              │
└──────────────┘                    └──────┬───────┘
                                           │
                                           ▼
                                    ┌──────────────┐
                                    │ Перевод в    │
                                    │ клетки:      │
                                    │ col=3, row=2 │
                                    └──────┬───────┘
                                           │
                              ┌────────────┴────────────┐
                              ▼                         ▼
                    ┌─────────────────┐       ┌─────────────────┐
                    │ selected=None   │       │ selected!=None  │
                    │ (выбор фигуры)  │       │ (перемещение)   │
                    └────────┬────────┘       └────────┬────────┘
                             │                         │
                             ▼                         ▼
                    ┌─────────────────┐       ┌─────────────────┐
                    │ board[2][3]!=None?│     │ board[new]=board[old]
                    │ ДА → selected=(2,3)│    │ board[old]=None
                    └────────┬────────┘       │ selected=None
                             │                └─────────────────┘
                             ▼
                    ┌─────────────────┐
                    │ Подсветка       │
                    │ жёлтым          │
                    └─────────────────┘
                                           │
                                           ▼
                                    ┌──────────────┐
                                    │  Рисование   │
                                    │  draw_board()│
                                    │  draw_pieces()│
                                    └──────┬───────┘
                                           │
                                           ▼
```
