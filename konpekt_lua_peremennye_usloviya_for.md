# Переменные, условия и цикл `for` в Lua

## Введение

В этом конспекте разобраны три базовые темы Lua:

- переменные типов `string`, `number` и `boolean`;
- условные конструкции `if`, `elseif`, `else`;
- числовой цикл `for` с началом, концом и шагом.

Примеры не используют ввод данных с клавиатуры. Все значения заранее записаны в программе.

---

## 1. Переменные

### Что такое переменная

Переменная — это имя, связанное со значением. Значение можно использовать в вычислениях, проверках и выводе.

```lua
local age = 15
print(age) -- 15

age = 16
print(age) -- 16
```

Слово `local` создаёт локальную переменную. В учебных примерах рекомендуется использовать именно `local`.

### Строки: `string`

`string` хранит текст. Текст записывается в кавычках:

```lua
local name = "Анна"
local city = 'Москва'

print(name)
print(city)
```

Строки можно объединять оператором `..`:

```lua
local firstName = "Иван"
local lastName = "Петров"

local fullName = firstName .. " " .. lastName
print(fullName) -- Иван Петров
```

### Числа: `number`

`number` используется для целых и дробных чисел:

```lua
local lives = 3
local price = 12.5

print(lives + 1)
print(price * 2)
```

Основные арифметические операторы:

```lua
local a = 10
local b = 3

print(a + b) -- сложение: 13
print(a - b) -- вычитание: 7
print(a * b) -- умножение: 30
print(a / b) -- деление
print(a % b) -- остаток от деления: 1
print(a ^ b) -- степень: 1000
```

### Логические значения: `boolean`

`boolean` может иметь только два значения: `true` или `false`.

```lua
local gameStarted = true
local doorOpen = false

print(gameStarted)
print(doorOpen)
```

Логические переменные удобно использовать в условиях:

```lua
local hasKey = true

if hasKey then
    print("Дверь можно открыть")
end
```

### Изменение переменной

```lua
local score = 0

score = score + 10
score = score + 5

print(score) -- 15
```

В Lua тип переменной определяется её значением. Технически тип можно изменить, но в учебных программах лучше давать переменной одно понятное назначение.

## 2. Сравнение значений

Сравнения возвращают `true` или `false`.

| Оператор | Значение |
|---|---|
| `==` | равно |
| `~=` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

```lua
local age = 18

print(age == 18) -- true
print(age > 20)  -- false
print(age ~= 15) -- true
```

Строки тоже можно сравнивать:

```lua
local password = "lua123"

if password == "lua123" then
    print("Пароль верный")
end
```

## 3. Условные конструкции

### Простая конструкция `if`

```lua
local temperature = 25

if temperature > 20 then
    print("На улице тепло")
end
```

Условие начинается с `if`, после выражения пишется `then`, а блок завершается словом `end`.

### Ветка `else`

```lua
local isDay = true

if isDay then
    print("Сейчас день")
else
    print("Сейчас ночь")
end
```

### Несколько вариантов: `elseif`

```lua
local score = 75

if score >= 90 then
    print("Отлично")
elseif score >= 60 then
    print("Сдано")
else
    print("Не сдано")
end
```

Lua проверяет условия сверху вниз и выполняет первую подходящую ветку.

### Логические операторы

Оператор `and` требует истинности обоих условий:

```lua
local age = 20
local hasTicket = true

if age >= 18 and hasTicket then
    print("Вход разрешён")
end
```

Оператор `or` требует истинности хотя бы одного условия:

```lua
local isAdmin = false
local isTeacher = true

if isAdmin or isTeacher then
    print("Доступ разрешён")
end
```

Оператор `not` меняет `true` на `false`, а `false` на `true`:

```lua
local doorLocked = false

if not doorLocked then
    print("Дверь открыта")
end
```

### Вложенные условия

```lua
local gameStarted = true
local hasWeapon = true

if gameStarted then
    if hasWeapon then
        print("Игрок готов")
    else
        print("Нужно найти оружие")
    end
else
    print("Игра ещё не началась")
end
```

## 4. Цикл `for`

Цикл `for` повторяет один и тот же блок команд несколько раз.

### Общая форма

```lua
for переменная = начало, конец, шаг do
    -- команды внутри цикла
end
```

У цикла есть три параметра:

1. начальное значение;
2. конечное значение;
3. шаг изменения.

Если шаг не указать, он равен `1`.

### Числа от 1 до 5

```lua
for i = 1, 5 do
    print(i)
end
```

Результат:

```text
1
2
3
4
5
```

Конечное значение включается в цикл.

### Цикл с шагом 2

```lua
for i = 0, 10, 2 do
    print(i)
end
```

Результат: `0`, `2`, `4`, `6`, `8`, `10`.

### Отрицательный шаг

```lua
for i = 5, 1, -1 do
    print(i)
end
```

Результат: `5`, `4`, `3`, `2`, `1`.

Для движения от большего числа к меньшему нужен отрицательный шаг.

### Сумма чисел в промежутке

```lua
local sum = 0

for i = 1, 5 do
    sum = sum + i
end

print(sum) -- 15
```

Переменная `sum` создаётся до цикла, чтобы сохранять результат между повторениями.

### Цикл с условием

```lua
for i = 1, 10 do
    if i % 2 == 0 then
        print(i .. " — чётное число")
    end
end
```

Цикл проходит по всем числам, а условие оставляет только чётные.

### Вложенный `for`

```lua
for row = 1, 3 do
    for column = 1, 4 do
        print("Строка: " .. row .. ", столбец: " .. column)
    end
end
```

Внутренний цикл полностью выполняется для каждого повторения внешнего цикла.

## 5. Типичные ошибки

### Ошибка 1. `=` вместо `==`

`=` используется для присваивания, а `==` — для сравнения.

```lua
local age = 18

if age == 18 then
    print("Возраст равен 18")
end
```

### Ошибка 2. Пропущено `then`

После условия обязательно пишется `then`:

```lua
if score > 50 then
    print("Успех")
end
```

### Ошибка 3. Пропущено `end`

Каждый `if` и каждый `for` должен завершаться `end`. Во вложенных конструкциях у каждого блока должен быть свой `end`.

### Ошибка 4. Неверный порядок границ

Для обратного отсчёта нужен отрицательный шаг:

```lua
for i = 5, 1, -1 do
    print(i)
end
```

### Ошибка 5. Нулевой шаг

Шаг `0` использовать нельзя: значение счётчика не будет изменяться. Для движения вперёд нужен положительный шаг, для движения назад — отрицательный.

### Ошибка 6. Путаница между строкой и числом

Оператор `..` объединяет значения как текст:

```lua
local number = 10
print("Число: " .. number) -- Число: 10
```

А оператор `+` выполняет сложение:

```lua
print(number + 5) -- 15
```

### Ошибка 7. Ожидание, что `0` — это `false`

В Lua число `0` считается истинным значением:

```lua
if 0 then
    print("Этот текст будет выведен")
end
```

Для проверки числа используйте сравнение:

```lua
local lives = 0

if lives == 0 then
    print("Жизни закончились")
end
```

## 6. Практические задачи

Все значения нужно записывать прямо в коде. Ввод с клавиатуры использовать не нужно.

### Задача 1. Проверка возраста

Создайте переменную `age` со значением `16`.

Если возраст меньше 18, выведите `Доступ запрещён`. Иначе выведите `Доступ разрешён`.

**Темы:** `number`, сравнение, `if`, `else`.

### Задача 2. Проверка пароля

Создайте строковую переменную:

```lua
local password = "lua123"
```

Если пароль равен `"lua123"`, выведите `Пароль верный`, иначе — `Пароль неверный`.

**Темы:** `string`, сравнение строк, `if`, `else`.

### Задача 3. Обработка результата

Создайте переменную `score` со значением от 0 до 100. Выведите сообщение по правилам:

- если `score` не меньше 90 — `Отлично`;
- иначе если `score` не меньше 60 — `Сдано`;
- иначе — `Не сдано`.

Проверьте программу со значениями `95`, `70` и `40`.

**Темы:** `number`, сравнение, `if`, `elseif`, `else`.

### Задача 4. Чётные числа с шагом

С помощью цикла `for` выведите чётные числа от 2 до 20:

```lua
for number = 2, 20, 2 do
    print(number)
end
```

Затем измените программу, чтобы она выводила нечётные числа от 1 до 19.

**Темы:** `for`, промежуток, шаг, `number`.

### Задача 5. Обратный отсчёт

С помощью цикла `for` выведите числа от 10 до 1 в обратном порядке.

Для каждого числа добавьте условие:

- если число равно `5`, выведите рядом текст `Половина пути`;
- для остальных чисел выводите только число.

Пример части результата:

```text
10
9
8
7
6
5 — Половина пути
```

**Темы:** `for` с отрицательным шагом, `if`, сравнение чисел, оператор `..`.

## Итог

Переменные `string`, `number` и `boolean` позволяют хранить текст, числа и логические значения. Условия помогают программе выбирать действие, а цикл `for` повторяет действие для чисел из заданного промежутка.

Главная форма числового цикла:

```lua
for i = начало, конец, шаг do
    -- команды
end
```

При решении задач проверяйте:

1. правильный ли тип значения используется;
2. написано ли `==`, если нужно сравнение;
3. закрыты ли блоки словами `end`;
4. подходит ли знак шага для выбранного направления цикла.
