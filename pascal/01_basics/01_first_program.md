# Урок 1. Первая программа, вывод и ввод

## Что узнаем

- из каких частей состоит программа Pascal;
- как выводить текст с помощью `writeln` и `write`;
- как получить ответ пользователя с помощью `readln`.

## Каркас программы

```pascal
program Hello;

begin
  writeln('Привет, мир!');
end.
```

`program Hello;` задаёт имя программы. После `begin` записываются команды. `end.` завершает программу; точка здесь обязательна. Точка с запятой разделяет команды.

![Части простой программы Pascal](../assets/pascal-program.png)

## Вывод

`writeln` печатает значение и переходит на следующую строку. `write` печатает без перехода.

```pascal
begin
  write('Меня зовут ');
  writeln('Аня');
  writeln('Я изучаю Pascal.');
end.
```

## Ввод

Для ввода объяви переменную, а затем прочитай в неё значение:

```pascal
program Greeting;
var
  name: string;
begin
  write('Как тебя зовут? ');
  readln(name);
  writeln('Привет, ', name, '!');
end.
```

Здесь `var` начинает раздел переменных, а `name: string;` объявляет строковую переменную. У `writeln` можно перечислять несколько значений через запятую.

## Практика

1. Выведи своё имя и любимый предмет на двух строках.
2. Спроси имя пользователя и поприветствуй его.
3. Спроси город и выведи фразу «Я живу в ...».
