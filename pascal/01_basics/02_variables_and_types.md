# Урок 2. Переменные, типы и арифметика

## Переменная — именованное место для данных

Перед использованием переменные объявляют после слова `var`:

```pascal
var
  age: integer;
  height: real;
  grade: char;
  city: string;
  isReady: boolean;
```

Часто используемые типы: `integer` — целое число, `real` — дробное, `char` — один символ, `string` — текст, `boolean` — `true` или `false`.

```pascal
program SumTwoNumbers;
var
  a, b, total: integer;
begin
  write('Первое число: ');
  readln(a);
  write('Второе число: ');
  readln(b);
  total := a + b;
  writeln('Сумма: ', total);
end.
```

Оператор `:=` присваивает значение. Это не знак равенства из математики: `total := a + b` означает «вычисли сумму и сохрани её в `total`».

## Арифметические операции

| Запись | Значение |
| --- | --- |
| `a + b` | сложение |
| `a - b` | вычитание |
| `a * b` | умножение |
| `a / b` | деление |
| `a div b` | целая часть от деления целых чисел |
| `a mod b` | остаток от деления |

Пример: `17 div 5` даёт `3`, а `17 mod 5` даёт `2`. Остаток удобно использовать для проверки чётности: `n mod 2 = 0`.

## Практика

1. Считай два целых числа и выведи сумму, разность и произведение.
2. Считай количество минут и выведи, сколько это полных часов и оставшихся минут.
3. Считай число и выведи остаток от деления на 10.
