# Урок 6. Процедуры и функции

Подпрограмма даёт имя группе команд, которую можно использовать повторно. Процедура выполняет действие, функция вычисляет и возвращает значение.

## Процедура

```pascal
program Greeting;

procedure SayHello;
begin
  writeln('Привет!');
end;

begin
  SayHello;
  SayHello;
end.
```

Процедура с параметром:

```pascal
procedure ShowSquare(value: integer);
begin
  writeln(value * value);
end;
```

Вызов `ShowSquare(4);` выведет `16`.

## Функция

```pascal
function Square(value: integer): integer;
begin
  Square := value * value;
end;
```

В Pascal имя функции используется для присваивания результата. Его можно сохранить в переменную:

```pascal
result := Square(6);
```

## Практика

1. Напиши процедуру, которая выводит линию из 10 звёздочек.
2. Напиши функцию, которая возвращает большее из двух целых чисел.
3. Напиши функцию, которая проверяет, является ли число чётным.
4. Раздели программу подсчёта суммы массива на ввод, вычисление суммы и вывод результата.
