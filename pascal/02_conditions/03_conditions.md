# Урок 3. Условия и логические выражения

Условие позволяет выбрать, какие команды выполнить.

```pascal
if temperature > 0 then
  writeln('Выше нуля')
else
  writeln('Ноль или ниже');
```

Если после `then` или `else` нужно выполнить несколько команд, их объединяют в `begin` и `end`:

```pascal
if score >= 50 then
begin
  writeln('Зачёт');
  writeln('Поздравляю!');
end
else
  writeln('Попробуй ещё раз');
```

Перед `else` точку с запятой не ставят. После последней команды всей программы точка ставится в `end.`.

## Операции сравнения

| Операция | Значение |
| --- | --- |
| `=` | равно |
| `<>` | не равно |
| `<`, `>` | меньше, больше |
| `<=`, `>=` | меньше или равно, больше или равно |

Условия можно объединять с помощью `and` («и»), `or` («или»), `not` («не»):

```pascal
if (age >= 7) and (age <= 17) then
  writeln('Школьный возраст');
```

Скобки помогают явно показать порядок проверки.

## Несколько вариантов

Для выбора из нескольких диапазонов можно вложить `if`:

```pascal
if score >= 90 then
  writeln('Отлично')
else if score >= 70 then
  writeln('Хорошо')
else
  writeln('Нужно потренироваться');
```

## Практика

1. Считай число и определи, положительное оно, отрицательное или равно нулю.
2. Определи, чётное число или нечётное, используя `mod`.
3. Считай два числа и выведи большее. Если они равны, сообщи об этом.
4. Считай балл от 0 до 100 и выведи оценку по выбранным тобой границам.
