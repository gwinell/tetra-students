# Lua для Roblox: Part, функции, циклы и условия

## Цель занятия

В этой работе ты научишься:

- создавать и изменять объекты `Part`;
- обращаться к свойствам объекта;
- объявлять и вызывать функции;
- использовать цикл `while`;
- использовать цикл `for`;
- проверять условия с помощью `if`, `elseif` и `else`.

Все примеры предназначены для Roblox Studio. Скрипты можно размещать в обычном `Script` внутри `ServerScriptService` или `Workspace`, если это отдельно указано в задании.

> В Roblox используется диалект Lua — Luau. Его синтаксис похож на обычный Lua, но он дополнен возможностями для Roblox.

## 1. Что такое Part

`Part` — базовый физический объект Roblox. Это деталь, из которой можно строить стены, платформы, препятствия и другие элементы карты.

Основные свойства `Part`:

| Свойство | Что делает | Пример |
|---|---|---|
| `Name` | задаёт имя объекта | `part.Name = "Block"` |
| `Size` | задаёт размер | `part.Size = Vector3.new(4, 1, 4)` |
| `Position` | задаёт положение | `part.Position = Vector3.new(0, 5, 0)` |
| `Color` | задаёт цвет | `part.Color = Color3.fromRGB(255, 0, 0)` |
| `Anchored` | закрепляет деталь | `part.Anchored = true` |
| `CanCollide` | включает столкновения | `part.CanCollide = true` |
| `Transparency` | задаёт прозрачность от `0` до `1` | `part.Transparency = 0.5` |

### Создание Part

Чтобы создать деталь через код, используется `Instance.new()`:

```lua
local part = Instance.new("Part")

part.Name = "MyBlock"
part.Size = Vector3.new(4, 1, 4)
part.Position = Vector3.new(0, 5, 0)
part.Color = Color3.fromRGB(0, 170, 255)
part.Anchored = true

part.Parent = workspace
```

`Parent = workspace` добавляет созданную деталь в игровую сцену. Если не указать `Parent`, объект существует в памяти, но игрок не увидит его в мире.

### Задержка с помощью `task.wait()`

Чтобы скрипт подождал некоторое количество секунд, используется:

```lua
task.wait(2) -- ожидание 2 секунды
```

Для Roblox лучше использовать `task.wait()`, а не старую функцию `wait()`.

## 2. Функции

Функция — это именованный блок команд, который можно запускать несколько раз.

```lua
local function sayHello()
	print("Привет, Roblox!")
end

sayHello()
```

Функция может принимать параметры:

```lua
local function createPart(position, color)
	local part = Instance.new("Part")
	part.Size = Vector3.new(2, 2, 2)
	part.Position = position
	part.Color = color
	part.Anchored = true
	part.Parent = workspace
	return part
end

createPart(Vector3.new(0, 2, 0), Color3.fromRGB(255, 0, 0))
createPart(Vector3.new(5, 2, 0), Color3.fromRGB(0, 255, 0))
```

В этом примере одна функция создаёт детали с разными положениями и цветами.

## 3. Условия

Условие позволяет выполнить код только тогда, когда выполняется определённое утверждение.

```lua
local coins = 10

if coins >= 10 then
	print("У игрока достаточно монет")
else
	print("Монет недостаточно")
end
```

Для нескольких вариантов используется `elseif`:

```lua
local height = 7

if height > 10 then
	print("Высокая платформа")
elseif height > 5 then
	print("Средняя платформа")
else
	print("Низкая платформа")
end
```

Основные операторы сравнения:

| Оператор | Значение |
|---|---|
| `==` | равно |
| `~=` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

Логические операторы:

- `and` — и;
- `or` — или;
- `not` — не.

Пример:

```lua
local isOpen = true
local hasKey = false

if isOpen or hasKey then
	print("Дверь можно открыть")
else
	print("Дверь закрыта")
end
```

## 4. Цикл `while`

Цикл `while` повторяет команды, пока условие истинно.

```lua
local count = 1

while count <= 5 do
	print("Номер: " .. count)
	count = count + 1
	 task.wait(1)
end
```

Важно изменять переменную, которая участвует в условии. Иначе цикл может стать бесконечным.

Пример изменения цвета детали:

```lua
local part = Instance.new("Part")
part.Size = Vector3.new(4, 1, 4)
part.Position = Vector3.new(0, 3, 0)
part.Anchored = true
part.Parent = workspace

local transparency = 0

while transparency <= 1 do
	part.Transparency = transparency
	transparency = transparency + 0.1
	task.wait(0.2)
end
```

## 5. Цикл `for`

Цикл `for` удобно использовать, когда заранее известно количество повторений.

```lua
for number = 1, 5 do
	print(number)
end
```

Третий параметр задаёт шаг:

```lua
for number = 10, 1, -1 do
	print(number)
end
```

### Создание нескольких Part

```lua
local function createPlatform(position, color)
	local platform = Instance.new("Part")
	platform.Size = Vector3.new(4, 1, 4)
	platform.Position = position
	platform.Color = color
	platform.Anchored = true
	platform.Parent = workspace
end

for i = 1, 5 do
	local x = (i - 1) * 5
	createPlatform(Vector3.new(x, 2, 0), Color3.fromRGB(255, 170, 0))
end
```

Этот скрипт создаёт пять платформ в ряд.

## 6. Полный пример: мигающая Part

```lua
local function createBlock()
	local block = Instance.new("Part")
	block.Name = "BlinkingBlock"
	block.Size = Vector3.new(5, 1, 5)
	block.Position = Vector3.new(0, 3, 0)
	block.Anchored = true
	block.Parent = workspace
	return block
end

local block = createBlock()

for cycle = 1, 5 do
	block.Color = Color3.fromRGB(255, 0, 0)
	task.wait(0.5)

	block.Color = Color3.fromRGB(0, 255, 0)
	task.wait(0.5)
end

if block.Anchored then
	print("Блок закреплён")
else
	print("Блок не закреплён")
end
```

В примере использованы все основные элементы урока: функция, создание `Part`, цикл `for`, условие и задержка.

---

## 7. Частые ошибки

1. **Забыли присвоить `Parent`.** Объект создан, но не появляется в мире.
2. **Забыли `end`.** Каждые `function`, `if`, `while` и `for` должны завершаться словом `end`.
3. **Бесконечный `while`.** Проверь, меняется ли переменная условия.
4. **Неправильный тип значения.** Для размера и позиции нужен `Vector3`, для цвета — `Color3`.
5. **Деталь падает.** Установи `part.Anchored = true`, если объект должен оставаться на месте.
6. **Скрипт запускается несколько раз.** Проверь, нет ли нескольких одинаковых `Script` в `Workspace` или `ServerScriptService`.

# Практические задачи

## Задача 1. Первый блок

Создай с помощью скрипта один `Part` со следующими свойствами:

- имя — `FirstBlock`;
- размер — `Vector3.new(6, 1, 6)`;
- позиция — `Vector3.new(0, 3, 0)`;
- любой цвет;
- деталь должна быть закреплена.

Проверь, что блок появился в `Workspace` и не падает.

## Задача 2. Функция для создания блока

Напиши функцию `createBlock(position, color)`, которая создаёт закреплённый блок размера `2 x 2 x 2`.

Вызови функцию три раза и создай три блока:

- красный в точке `(0, 2, 0)`;
- зелёный в точке `(4, 2, 0)`;
- синий в точке `(8, 2, 0)`.

## Задача 3. Ряд платформ через `for`

С помощью цикла `for` создай 10 платформ в ряд. Расстояние между платформами должно быть 5 studs.

Подсказка: координату можно вычислять так:

```lua
local x = (i - 1) * 5
```

## Задача 4. Проверка размера через условие

Создай функцию, которая принимает `Part` и проверяет его высоту:

- если высота больше 5 — вывести `"Высокий блок"`;
- если высота равна 5 — вывести `"Средний блок"`;
- иначе вывести `"Низкий блок"`.

Для получения высоты используй `part.Size.Y`.

## Задача 5. Изменение прозрачности через `while`

Создай блок и постепенно увеличивай его прозрачность от `0` до `1` с шагом `0.1`.

Между изменениями делай паузу `0.2` секунды. После завершения цикла выведи в консоль сообщение `"Блок исчез"`.

## Задача 6. Обратное появление блока

Дополни предыдущую задачу: после исчезновения блока запусти второй цикл `while`, который уменьшает прозрачность от `1` до `0`.

В результате блок должен плавно исчезнуть, а затем плавно появиться.

## Задача 7. Светофор

Создай три `Part` — красный, жёлтый и зелёный.

С помощью `for` повтори 3 раза последовательность:

1. включить красный цвет на 2 секунды;
2. включить жёлтый цвет на 1 секунду;
3. включить зелёный цвет на 2 секунды.

Остальные детали в каждый момент должны быть тёмными или прозрачными.

## Задача 8. Мини-обби

Создай 8 платформ с помощью функции и цикла `for`.

Требования:

- каждая следующая платформа выше предыдущей на 1 stud;
- каждая вторая платформа должна быть красной, остальные — синей;
- если номер платформы больше 5, её размер должен быть `3 x 1 x 3`, иначе — `5 x 1 x 5`;
- после создания всех платформ выведи сообщение `"Мини-обби готово"`.

## Дополнительное задание

Сделай движущуюся платформу. Она должна перемещаться по оси `X` от `-10` до `10`, используя цикл `while`. Когда платформа достигнет координаты `10`, она должна начать двигаться обратно к `-10`.

Используй:

- функцию для создания платформы;
- условие для смены направления;
- `while` для постоянного движения;
- `task.wait()` для плавности.
